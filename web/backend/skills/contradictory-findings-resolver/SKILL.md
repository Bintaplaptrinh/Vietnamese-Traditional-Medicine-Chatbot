# Conflicting evidence in Bloop

Compare the exact claims and their source boundaries before calling them a
contradiction: population, disease stage, preparation, dose, comparator, endpoint,
timing, specimen/model, assay, adjustment and validation depth.

Separate true opposing findings from different endpoints, populations, methods,
effect magnitudes or interpretation. A conflict_group is a comparison flag,
not proof that multiple objects or statements are incompatible.

Attribute findings to each source with its own citation IDs. Resolve by supported
scope differences or evidence limits; never invent a methodological explanation,
choose a winner by source count, or silently hide the less convenient source.
If the material cannot resolve a disagreement, preserve that uncertainty. A
supported description of disagreement is allowed; an unsupported treatment
recommendation or manufactured consensus is not.
